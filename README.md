# Guitar Chord Viewer

기타 코드를 입력하면 운지법(프렛 위치)을 두 가지 다이어그램으로 보여주는 PySide6 GUI 프로그램입니다. 두 개의 외부 데이터셋과 자체 알고리즘을 통합해 한 코드당 최대 60개의 운지법을 제공합니다. 반대로 지판을 클릭해 만든 모양의 코드명도 찾을 수 있습니다.

## 파일 구성

```
guitar_chord/
├── app.py                # PySide6 GUI 진입점 (실행 파일)
├── chord_parser.py       # 입력 문자열 파싱 + 구성음 계산
├── voicings.py           # 내장 DB + 자동 생성기 + 외부 데이터 통합 + 역검색(운지→코드명)
├── chord_chart.py        # 좌(운지)/우(음) 차트를 그리는 QPainter 위젯 (클릭 입력 포함)
├── diagram.py            # 텍스트 다이어그램 렌더러 (Copy text용) + 표시 프렛 범위 결정
├── external_data.py      # 외부 데이터셋 어댑터 (chords-db / T-vK)
├── guitar_chord.spec     # PyInstaller 빌드 설정
├── guitar.ico            # 앱 아이콘
└── data/
    ├── chords_db_guitar.json        # tombatossals/chords-db (MIT)
    └── tvk_chords_complete.json     # T-vK/chord-collection (GPL)
```

## 실행 방법

```bash
python app.py
```

GUI는 PySide6로 구현되어 있어 `pip install PySide6` 설치가 필요합니다. 그 외에는 Python 3.10+ 표준 라이브러리만 사용합니다. `data/` 폴더의 JSON 파일들은 함께 두어야 외부 운지법이 로드됩니다.

### 빌드 (Windows 실행 파일)

```bash
pyinstaller guitar_chord.spec
```

`dist\guitar_chord.exe` 단일 파일(아이콘 포함, 콘솔 창 없음)이 생성됩니다. `data/` JSON과 아이콘이 exe 안에 포함되므로 exe만 배포하면 됩니다.

## 데이터 소스 (운지법)

| 소스 | 라이선스 | 운지법 수 | 비고 |
|------|---------|----------|------|
| 내장 DB (수기) | — | 41개 (27개 코드) | 가장 정통적인 오픈/바레 코드 |
| **chords-db** (tombatossals) | MIT | 약 3,300개 | 깔끔, 12개 키 × 86 종류 |
| **T-vK chord-collection** | GPL | 약 67,000개 | 파일의 12,852개 코드명 중 지원하는 코드 종류만 로드 |
| 자동 생성 (알고리즘) | — | 가변 | DB에 없는 코드 폴백 |

**Both** 소스에서는 DB 운지법을 먼저, 이어서 자동 생성 운지법을 붙여 최대 60개까지 표시합니다. 예: `C`는 DB 25개 + 자동 생성으로 60개(상한), `F#m7/B`는 23개(모두 T-vK)입니다.

외부 데이터셋의 운지법 중 코드 구성음(분수 코드는 베이스음 포함)이 아닌 음이 나는 항목은 데이터 오류로 보고 로드 시 제외합니다 (13·M13 코드는 11음 허용).

## 입력 규칙

- **첫 글자**: `A`~`G` 대문자 (필수, 루트 음)
- **두 번째 글자(선택)**: `#` 또는 `b` (소문자 b = 플랫 ♭)
- **그 이후(선택)**: 코드 종류
  - 대문자 `M` = maj
  - 소문자 `m` = min
  - `7`, `maj7`(=`M7`), `min7`(=`m7`), `M9`, `m9`, `m7b5`, `sus2`, `sus4`, `dim`, `dim7`, `aug`, `aug7`, `add9`, `5`(파워 코드), `6`, `9`, `11`, `13`
  - 확장 코드(20종): `m6`, `m11`, `madd9`, `m69`(=`m6/9`), `add11`, `69`(=`6/9`), `7sus4`, `7sus2`, `sus2sus4`, `7b5`, `7b9`, `7#9`, `9b5`, `9#11`, `aug9`(=`+9`), `M7b5`, `M7#5`, `M7sus2`, `M11`, `M13`
  - 기호·단어 표기: `△`/`Δ`(=`M`), `°`(=`dim`), `ø`(=`m7b5`), `+`(=`aug`), 루트 바로 뒤 `-`(=`m`), `major`/`minor`/`augmented`/`diminished`
- **분수 코드**: `/<bass>` 추가 (예: `C/G`)

### 예시
| 입력 | 의미 |
|------|------|
| `C` | C 메이저 |
| `CM` | C 메이저 (동일) |
| `Cm` | C 마이너 |
| `C7` | C 도미넌트 세븐 |
| `CM7` | C 메이저 세븐 |
| `Cm7` | C 마이너 세븐 |
| `Bb` | B플랫 메이저 |
| `Bbm7` | B플랫 마이너 세븐 |
| `F#` | F샵 메이저 |
| `C/G` | C 메이저, G 베이스 |
| `F#m7/B` | F샵 마이너 세븐, B 베이스 |
| `C6/9` | C 식스나인 (`C69`와 동일) |

지원하지 않는 입력: `bb`(더블플랫), `##`(더블샵), `mM`(마이너-메이저 7 등 복합).

## 사용 방법

### 코드명으로 운지법 찾기

1. **Input Chord** 필드에 코드명 입력 후 Enter 또는 **Show** 클릭
2. 패널 양옆의 **◀ / ▶** 버튼으로 같은 코드의 다른 운지법 이동 (처음/마지막에서는 해당 화살표 비활성)
3. 하단에 **현재/전체** 운지법 번호와 **소스 태그**(`[DB]`, `[chords-db]`, `[T-vK]`, `[Auto]`) 표시

**Fingering Source** 라디오 버튼으로 운지법 소스를 선택합니다.

- **DB**: 내장 DB + 외부 JSON 데이터셋 (chords-db, T-vK)
- **Auto**: 알고리즘이 이론적으로 가능한 운지법 탐색
- **Both**: DB + Auto, 중복 제거 (기본)

### 운지법으로 코드명 찾기

좌측 운지 차트를 직접 클릭해 모양을 만들면 클릭할 때마다 바로 코드명을 판정합니다 (Show 불필요). 시작 시와 오류 후에는 좌측에 모든 줄이 개방현인 빈 지판이 표시됩니다.

- 줄의 프렛 칸 클릭 = 그 줄을 해당 프렛으로 누름 (줄당 점 1개 — 같은 줄 다른 칸을 누르면 점이 이동)
- 이미 찍힌 점을 다시 클릭 = 지우고 개방현으로 되돌림
- 너트 왼쪽 `o`/`x` 자리 클릭 = 개방현 ↔ 뮤트 전환
- 건드리지 않은 줄은 **개방현**으로 간주
- 마우스를 올리면 클릭될 칸에 옅은 점으로 미리보기
- 높은 포지션: 좌측 차트 위에서 마우스 휠, 또는 **◀ Fret / Fret ▶** 버튼으로 표시 시작 프렛 이동 (1~20fr, 항상 5칸 표시, 최대 24프렛)
- **Clear**: 모든 줄 개방현의 빈 상태로 초기화 (첫 클릭 전에는 판정하지 않음)
- **Exact match**: 소리 나는 음이 코드 구성음과 완전히 일치하면 해당 코드를 표시 (확장 코드 20종 포함)
- **Fallback**: 일치하는 코드가 없으면 기본 코드 종류(확장 코드 20종 제외) 중 가장 근사한 코드를 표시하며 배너에 *Exact match not found* 안내
- 서로 다른 음이 2개 미만이면 *Click at least 2 strings with different notes.*, 근사한 코드도 없으면 *No matching chord for these notes.* 를 배너에 표시 (우측 차트는 비움)
- 판정 결과는 배너·구성음·우측 음 차트에 즉시 반영. 하단은 `-/-` `[Custom shape]`로 표시되고 ◀ / ▶ 는 비활성. 우측 음 차트도 좌측과 같은 프렛 범위를 표시
- 같은 음 구성으로 다르게 부를 수 있는 이름(정확히 일치하는 것만)은 배너 아래 `= C6` 같은 칩으로 최대 4개 표시 (예: `x02010`은 `Am7`, 칩 `= C6`). 칩을 누르면 그 코드명으로 검색 (코드명 입력 후 Show와 동일)
- 코드명으로 찾은 운지법이 보이는 상태에서 클릭하면 그 운지법에서 출발해 편집 (Fingers 표시 모드여도 직접 만든 모양은 점으로 표시)

> **두 입력 방식은 상호 배타적입니다.**  
> 차트를 클릭하면 Input Chord 필드가 자동으로 지워지고,  
> 코드명을 입력하고 Show를 누르면 기존처럼 코드명 검색으로 돌아갑니다.

## 다이어그램 읽는 법

두 패널 모두 줄을 가로로 그립니다. 맨 위가 1번줄(하이 e), 맨 아래가 6번줄(저음 E)이고 저음 줄일수록 선이 굵습니다. 프렛 번호는 왼쪽에서 오른쪽으로 커집니다.

- 왼쪽 열: 줄 이름(e B G D A E), 그 오른쪽(너트 왼쪽)에 `o`=개방현, `x`=뮤트(연주 안 함)
- 박스 왼쪽 굵은 세로선 = 너트(1프렛부터 표시할 때). 높은 포지션은 너트 대신 첫 프렛 칸 아래에 `8fr`처럼 시작 프렛 번호를 표시
- 점은 해당 줄 위, 두 프렛선 사이에 표시
- 두 패널 모두 항상 5프렛 폭으로 표시하고, 시작 프렛은 운지에 맞춰 자동 결정 (Copy text의 텍스트 다이어그램은 기존처럼 3~5프렛)
- 표시 범위 밖에 점이 있는 줄은 칸 끝에 `‹3`, `12›`처럼 프렛 번호 표시
- 루트음은 파란색(점·음 이름)으로 강조

### 좌측 (운지 차트)

**Display** 라디오 버튼으로 표시 방식을 고릅니다 (좌측 패널에만 적용).

- **Dots**: 누르는 위치만 점으로 표시 (기본)
- **Fingers**: 점 안에 손가락 번호(1=검지 ~ 4=새끼) 표시
- **Fingers + Barre**: 손가락 번호 + 바레(한 손가락으로 여러 줄을 누르는 세로 막대)
  - chords-db: 데이터의 `fingers`, `barres` 값을 사용 (바레는 개방현이나 더 낮은 프렛을 누른 줄을 가로지르지 않도록 나눔)
  - T-vK: 데이터의 `fingerings` 값을 사용하고, 같은 손가락이 같은 프렛에서 2줄 이상을 누르면 바레로 표시
- 손가락 데이터가 없거나 프렛과 맞지 않아 버린 운지법(일부 외부 데이터, 내장 DB 일부, Auto 생성)은 점만 표시하고 상단에 *No fingering data for this voicing* 안내
- 박스 오른쪽 열: 각 줄이 내는 음 이름

### 우측 (음 차트)

좌측과 같은 박스·프렛 범위에서 각 점 안에 그 줄이 내는 음 이름을 표시합니다.

- 개방현은 `o` 자리에 음 이름(예: `E`), 뮤트는 `x`
- 박스 오른쪽 열: 각 줄에서 누르는 프렛 번호

### 복사·저장

각 패널을 우클릭하면 메뉴가 뜹니다.

- **Copy image**: 해당 패널 그림을 클립보드로 복사 (패널에 포커스가 있을 때 Ctrl+C도 동일. 우측은 더블클릭도 동일 — 좌측은 클릭이 편집이라 더블클릭 복사 없음)
- **Copy text**: 기존 텍스트 다이어그램 복사 (좌측=프렛보드 텍스트, 우측=프렛+음 텍스트)
- **Save as PNG…**: PNG 파일로 저장. 저장 실패 시 안내 창 표시
- 직접 클릭해 만든 모양도 복사·저장 가능 (판정되지 않은 모양은 좌측만, 파일명 `custom_fingering.png`)

### 로그 파일

파일 로드·변환·저장 오류는 `%LOCALAPPDATA%\GuitarChordViewer\guitar_chord.log`에 기록됩니다 (최대 512 KB, 백업 1개). 폴더를 만들 수 없으면 로그 없이 실행됩니다.
