# Guitar Chord Viewer

기타 코드를 입력하면 운지법(프렛 위치)을 두 가지 다이어그램으로 보여주는 Tkinter GUI 프로그램입니다. 두 개의 외부 데이터셋과 자체 알고리즘을 통합해 한 코드당 수십~수백 개의 운지법을 제공합니다.

## 파일 구성

```
guitar_chord/
├── app.py                # Tkinter GUI 진입점 (실행 파일)
├── chord_parser.py       # 입력 문자열 파싱 + 구성음 계산
├── voicings.py           # 내장 DB + 자동 생성기 + 외부 데이터 통합
├── diagram.py            # 좌/우 두 종류의 다이어그램 텍스트 렌더러
├── external_data.py      # 외부 데이터셋 어댑터 (chords-db / T-vK)
└── data/
    ├── chords_db_guitar.json        # tombatossals/chords-db (MIT)
    └── tvk_chords_complete.json     # T-vK/chord-collection (GPL)
```

## 실행 방법

```bash
python app.py
```

GUI는 PySide6로 구현되어 있어 `pip install PySide6` 설치가 필요합니다. 그 외에는 Python 3.10+ 표준 라이브러리만 사용합니다. `data/` 폴더의 JSON 파일들은 함께 두어야 외부 운지법이 로드됩니다.

## 데이터 소스 (운지법)

| 소스 | 라이선스 | 운지법 수 | 비고 |
|------|---------|----------|------|
| 내장 DB (수기) | — | ~30개 | 가장 정통적인 오픈/바레 코드 |
| **chords-db** (tombatossals) | MIT | 약 3,300개 | 깔끔, 12개 키 × 86 종류 |
| **T-vK chord-collection** | GPL | 약 67,000개 | 12,852개 코드명, 매우 광범위 |
| 자동 생성 (알고리즘) | — | 가변 | DB에 없는 코드 폴백 |

C 메이저 한 코드만 봐도 **148개 운지법**, F#m7/B 같은 분수 코드는 **23개 운지법**이 검색됩니다.

## 입력 규칙

- **첫 글자**: `A`~`G` 대문자 (필수, 루트 음)
- **두 번째 글자(선택)**: `#` 또는 `b` (소문자 b = 플랫 ♭)
- **그 이후(선택)**: 코드 종류
  - 대문자 `M` = maj
  - 소문자 `m` = min
  - `7`, `maj7`(=`M7`), `min7`(=`m7`), `sus2`, `sus4`, `dim`, `dim7`, `aug`, `aug7`, `add9`, `6`, `9`, `11`, `13`
- **분수 코드**: `/<bass>` 추가 (예: `C/G`)

### 예시
| 입력 | 의미 |
|------|------|
| `C` | C 메이저 |
| `CM` | C 메이저 (동일) |
| `Cm` | C 마이너 |
| `C7` | C 도미넌트 세븐 |
| `CM7` | C 메이저 세븐 |
| `Cm7` | C 마이너 세븐 |
| `Bb` | B플랫 메이저 |
| `Bbm7` | B플랫 마이너 세븐 |
| `F#` | F샵 메이저 |
| `C/G` | C 메이저, G 베이스 |
| `F#m7/B` | F샵 마이너 세븐, B 베이스 |

지원하지 않는 입력: `bb`(더블플랫), `##`(더블샵), `mM`(마이너-메이저 7 등 복합).

## 사용 방법

### 코드명으로 운지법 찾기 (기존)

1. **Input Chord** 필드에 코드명 입력 후 Enter 또는 **Show** 클릭
2. **◀ / ▶** 버튼으로 같은 코드의 다른 운지법 이동
3. 하단에 **현재/전체** 운지법 번호와 **소스 태그** 표시

### 운지법으로 코드명 찾기 (신규)

우측 **e / B / G / D / A / E** 입력 박스에 각 줄의 프렛 번호를 입력하고 **Show** 클릭.

- 숫자만 입력 가능 (0 = 개방현, 1 이상 = 해당 프렛)
- 모든 줄을 입력할 필요 없음 — 비워두면 해당 줄은 무시
- **Exact match**: 입력한 음정이 코드 구성음과 완전히 일치하면 해당 코드를 표시
- **Fallback**: 일치하는 코드가 없으면 가장 근사한 코드를 표시하며 배너에 *Exact match not found* 안내
- 식별된 코드명은 **Input Chord** 필드에 자동 입력되고, 해당 코드의 모든 운지법이 동시에 표시됨

> **두 입력 모드는 상호 배타적입니다.**  
> Input Chord 필드에 타이핑하면 프렛 박스가 자동으로 지워지고,  
> 프렛 박스에 입력하면 Input Chord 필드가 자동으로 지워집니다.

### 공통

- **운지법 소스** 라디오 버튼으로 선택:
   - **DB**: 내장 DB + 외부 JSON 데이터셋 (chords-db, T-vK)
   - **Auto**: 알고리즘이 이론적으로 가능한 운지법 탐색
   - **Both**: DB + Auto, 중복 제거 (기본)
- 처음/마지막에서는 해당 화살표 비활성화

## 다이어그램 읽는 법

### 좌측 (프렛보드)

```
eo|---|---|---|       e=1번줄(하이e), o=개방현
B |-o-|---|---|       1프렛 누름
Go|---|---|---|       3번줄 개방현
D |---|-o-|---|       2프렛 누름
A |---|---|-o-|       3프렛 누름
Ex|---|---|---|       x=뮤트(연주 안 함)
```

- 현 이름 옆 글자: `o`=개방현, `x`=뮤트, 공백=프렛을 눌러 연주
- 기본 3프렛까지 표시, 운지가 4·5프렛까지 있으면 자동 확장
- 5프렛을 넘는 운지법(예: 8프렛부터 시작하는 바레)은 시작 프렛 번호를 아래에 표시

### 우측 (잡는 프렛 + 음계)

```
eo|-(E)--|       개방현이라 프렛 번호 없이 (E)음
B |-1(C)-|       1프렛 누르면 C음
Go|-(G)--|       개방현 G음
D |-2(E)-|       2프렛 E음
A |-3(C)-|       3프렛 C음
Ex|------|       뮤트
```

폰트는 Consolas 고정폭 글꼴로 그리드 정렬을 유지합니다.
